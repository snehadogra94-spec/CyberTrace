CyberTrace

Digital Evidence Analyzer Tool

Built during internship at Cyber Police Station Jammu  ·  Developed by Sneha Dogra,

A Python-based forensic tool that automates digital investigation tasks — IP geolocation, email header tracing, malicious URL detection, CDR call record analysis, and automated PDF report generation.

🌐

IP Analyzer

Geolocate any IP address. Find country, city, ISP and organisation details instantly.
📧

Email Header Analyzer

Trace the origin of any email. Detect spoofing, extract routing IPs, check SPF and DKIM.
🔗

URL Scanner

Scan any suspicious link against 70+ antivirus engines via VirusTotal API.
📞

CDR Parser

Upload call detail records CSV. Get charts, top callers, and contact network graph.
